# BlockComet

Minecraft launcher for Android (based on Copper), with Meteor/Fabric instances, a skin gallery, content browser and in-game video recording.

**Download the latest APK:** https://github.com/justaguyLV/BlockComet-download/releases/latest/download/BlockComet.apk
